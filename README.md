# studenchesky
Название приложения: Электронный студенческий

Суть приложения: Цифровой аналог студенческого билета с динамическим QR-кодом для прохода в колледж и встроенным кошельком для хранения бонусов, которые можно тратить на еду. 

Описание приложения: «Электронный студенческий» — это современное мобильное приложение от Команды 5, которое превращает смартфон в полноценную замену пластиковому пропуску и бумажному студенческому билету. Оно объединяет систему контроля доступа в колледж и программу лояльности, превращая спортивные достижения студентов в реальные бонусы для оплаты питания.
